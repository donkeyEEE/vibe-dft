# 由 Domain Research 指导 Spec 研究推理，取消证据档位

Spec 设计中的研究逻辑由 `domain-research` 统一指导，运用物理因果链分析机制和证据，
运用计算剪枝选择模型、参数探索及精度投入。`calc-to-spec` 负责将建议组织为可执行的
Spec，并处理设计模式、授权和发布；科学承诺仍以 Spec 为权威记录。

每份 Spec 围绕一个连贯研究目标，可以包含关联的探索与判断。Task 保留 Purpose 和
Acceptance，探索任务可通过取得指定观察、诊断或比较完成；科学结论根据结果判断。
验证投入、定量阈值和停止规则按研究目的与物理依据决定，科学证据缺口可以成为探索任务的
目的。后端参考提供软件事实、方法适用条件和诊断选项，避免另设统一研究门槛。

取消 `light | strict` 证据档位及其选择、默认、继承和写入规则，用户具体验证要求记录在
RQ 或 Spec 的科学要求中。旧 Spec 保留原样，继续按其显式承诺和验收执行；历史档位字段
不为新设计推导额外检查。此次维护不批量改写旧 RQ 或 Spec。

本决策修订 ADR-0017 的单一主要判断、证据档位及统一完整性要求，修订 ADR-0019 对证据
档位和必备停止规则的引用，以及 ADR-0020 中研究条件判断的职责分工。设计模式、RQ 边界、
ID 与无环依赖、执行授权、旧 Run 保留、替换安全和 concluded 重开授权继续有效。
