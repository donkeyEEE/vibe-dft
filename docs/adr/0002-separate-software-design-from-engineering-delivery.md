# Separate software design from engineering delivery

The two Dev Project plugins will be divided by responsibility rather than by generic productivity labels: `dev-productivity` owns software product definition, requirements and solution design plus the collaboration practices that support them, while `dev-engineering` owns implementation, verification and codebase maintenance. Design-oriented skills will move to `dev-productivity`, but code-structure design remains part of engineering delivery; `triage`, the cross-stage `ask-matt` router and repository setup remain in `dev-engineering` so request verification, delivery orchestration and tracker configuration stay together without creating additional skills.
