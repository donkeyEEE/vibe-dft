# 将低频假设留到出现迹象时处理

相关研究推理职责、Spec 目标与证据档位规则已由 [ADR-0021](0021-guide-spec-reasoning-with-domain-research.md) 修订；以下保留原决策记录。

RQ 和 Spec 只预先写入当前研究路径需要的条件：已有迹象表明可能触发的分支、决定科学结论是否有效的前提，或事后处理会造成重大代价的风险。其他低频假设即使可能改变后续判断，也留到出现具体迹象时再处理；不靠重复的限制语制造严谨感。

`domain-research` 在写作审视中识别这类多余限制，`calc-rq` 和 `calc-to-spec` 仍负责判断条件是否影响各自的科学问题、验收或停止规则。这样既保留必要的科学边界，也让记录集中于当前要作的决定。
