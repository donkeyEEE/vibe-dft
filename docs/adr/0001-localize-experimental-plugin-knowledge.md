# Localize experimental knowledge within consuming plugins

The shared `research-knowledge` boundary has no demonstrated cross-plugin formal resources, while its fixed external path makes independently released plugins non-portable. We will replace it with optional plugin-local knowledge bases: paper writing and journal cards belong to `paper-project`, while calculation templates, physics cards, and ontology cards move to `calc-project`; ontology remains explicitly incubating rather than formal Calc Project domain knowledge. The top-level shared directory will be removed after migration without a compatibility copy, while Cangjie write behavior and long-term plugin knowledge admission, promotion, and governance remain deliberately undecided.
