# Keep upstream engineering skills outside YZ Skills

Supersedes: ADR 0004.

The user wants to gain experience with the upstream engineering skills before
making personal changes. YZ Skills therefore stops maintaining a personal copy
and ends the selection exercise. The repository maintains only Calc Project,
Paper Project, and OSM Project.

Calculation project initialization clarifies the necessary project terminology
directly. It does not require an engineering interview plugin. This repository
change does not install, remove, or modify externally installed skills.

Removal paths and lifecycle baselines are recorded in the migration log.
