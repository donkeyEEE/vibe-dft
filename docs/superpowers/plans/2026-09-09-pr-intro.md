# PR Introduction Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, and run the first evaluation-driven optimization of the `pr-intro` Paper Project skill using the Zotero collection `PRL/APS论文素材库`.

**Architecture:** One lightweight skill router separates ordinary Physical Review Introduction writing from an explicitly invoked maintenance branch. A deterministic Python builder creates a persistent local masked-continuation dataset from Zotero; the primary agent then evaluates isolated continuation agents against a baseline and mutable candidate copy before applying only a passing candidate patch.

**Tech Stack:** Markdown Codex skills, YAML agent interface, Python 3 standard library, Zotero Desktop local API, JSON/JSON Schema, pytest, git.

**Spec:** `docs/superpowers/specs/2026-09-09-pr-intro-design.md`

## Global Constraints

- Runtime writing must not load evaluation data, Zotero-derived content, or maintenance instructions.
- The maintenance route is entered only by an explicit request to optimize `pr-intro`.
- Published Introduction text, fact packets, continuations, and run artifacts remain in a gitignored local data root and outside the plugin release.
- Child-agent case views contain no title, author, DOI, Zotero key, source path, reference continuation, or inherited parent conversation.
- The formal dataset contains exactly 20 eligible papers split by paper into 15 development and five acceptance papers.
- Each eligible paper contributes at most one SCC and one FGCC.
- `SKILL.md` and designated writing references are mutable; maintenance instructions, evaluation rules, schemas, scripts, and tests are immutable during optimization.
- Final application changes the working tree but does not create a Git commit.
- Preserve unrelated user changes and stop rather than overwrite source drift.
