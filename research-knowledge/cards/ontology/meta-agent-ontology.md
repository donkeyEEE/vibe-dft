# Agent Ontology

Agent Ontology 是对 LLM 提案、工具选择和步骤组织施加机器可校验语义边界的治理模型，其对象是非确定性决策过程，而不是确定性业务函数本身。

## Caveats

“Agent Ontology”是来源作者对多种实践的归纳，不应表述成已经存在统一语法、统一标准或单一产品实现。
