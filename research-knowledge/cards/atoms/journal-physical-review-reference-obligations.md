# Physical Review reference obligations

Physical Review authors must provide a complete and accurate reference set that communicates the precedents, sources, and context of the work and keep it updated throughout review and publication.

## Requirements

Number body citations consecutively by first appearance. Do not use numbered references in the abstract; any indispensable source there must be written out directly. Include every cited source, including citations appearing only in figure or table captions, in the reference list. Prefer published primary references over e-prints when the published source exists, and verify all bibliographic data.

## Caveats

Detailed formatting differs by source type and can change. Consult a recent article in the target Physical Review journal and the current APS style guide before submission.
