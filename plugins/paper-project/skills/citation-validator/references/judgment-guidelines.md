# 判断指南 — 当摘要不够时

## 摘要充足性判断

读摘要后自问以下问题，全部回答"是"才是摘要充足：

1. 我能明确说出这篇论文的研究对象吗？
2. 我能明确说出这篇论文的核心发现/结论吗？
3. 我能判断这篇论文的方法/技术路线吗？
4. 我能将这些信息与声明进行对比吗？

如果任何一个回答"否"，摘要不充足，需要获取全文片段。

## 从全文中提取关键信息

获取全文后，不读全文，而是搜索关键句：

### 搜索目标句

1. **结论句**: 在 `Conclusion` / `Summary` / `In summary` / `We conclude` 附近
2. **发现句**: 在 `We found` / `We demonstrate` / `Our results show` / `We observe` 附近
3. **方法句**: 在 `Methods` / `Experimental` / `Computational details` 开头
4. **限制句**: 在 `However` / `limitation` / `future work` / `should be noted` 附近

### 搜索技巧

```bash
grep -n -i "we found\|we demonstrate\|in conclusion\|our results" /tmp/fulltext.txt | head -20
```

## 常见判断困境

### 困境 1: 摘要只说"研究了 X"，未说发现了什么

**处理**: 获取全文。如果全文也未给出明确结论，评为 `background_support`。

```
推理: 该论文研究了 X 但摘要/全文未提供可验证的结论性发现。
无法判断其是否支撑"Y 导致 Z"的声明。仅能作为领域背景引用。
```

### 困境 2: 论文与声明使用相同方法但不同材料

**处理**: 如果声明是关于方法的，评为 `partial_support`；如果声明是关于材料性质的，评为 `no_evidence`。

```
推理: 声明主张 Fe₃GeTe₂ 的居里温度与空位浓度关系，但该论文使用相同 DFT 方法
研究了 CrI₃。方法支撑成立（partial），但材料性质主张不成立。
```

### 困境 3: 预印本 vs 正式发表

**处理**: 如果 Zotero 中同时有预印本和正式版，使用正式版。如果仅有预印本，标注 `[预印本]`，按相同标准评估。

### 困境 4: 综述引用

综述本身不是一手证据。如果声明是背景性陈述，综述可作为背景支撑。如果声明是实验性结论，综述应降级为 `partial_support` 并建议替换为原始论文。

```
推理: 该引用为综述论文，归纳了领域内多项研究。对于背景性声明可作为背景支撑，
但对于实验性声明"X 的居里温度为 200 K"，建议替换为直接测量该值的原始论文。
```

### 困境 5: 论文与声明"看起来相关"但实质不同

最危险的误判。常见陷阱：
- 研究同一材料但不同性质（如声明磁性，论文研究电输运）
- 研究同一方法但不同体系（如声明 Fe₃GeTe₂，论文 CrI₃）
- 研究同一现象但不同机制（如声明空位效应，论文应变效应）

**处理**: 严格区分。如果核心变量不同，评为 `no_evidence`。

```
推理: 该论文研究了 Fe₃GeTe₂ 的电输运性质，但声明涉及的是磁性（居里温度）。
虽然材料相同，但研究的物理性质完全不同，无法支撑该声明。
```

## 快速判断流程

```
摘要 → 明确研究对象？明确结论？→ 是 → 对比声明 → 评级
                    ↓ 否
                获取全文 → 搜索结论段 → 明确？→ 是 → 评级
                                    ↓ 否
                              background_support
```
