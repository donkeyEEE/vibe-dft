# 支撑等级评估框架

改编自 `nature-citation` skill 的支撑分级体系，用于判断一篇被引文献是否真正支撑论文中的某处声明。

## 五级评估标准

### 🟢 强支撑 (strong_support)

**定义**: 论文直接验证了与声明相同的核心关系/机制/方法，研究结果正面支持该声明。

**适用条件**（满足 ≥2 条）：
- 论文的研究对象/体系与声明一致
- 论文的核心结论与声明方向相同
- 论文的方法/模型可直接支撑声明中的方法论主张
- 声明中的定量结果与论文的结果在量级上一致

**示例**:
- 声明："Fe₃GeTe₂ 的居里温度随 Fe 空位浓度增加而降低"
- 支撑论文：直接测量了不同 Fe 空位浓度下 Fe₃GeTe₂ 的居里温度，发现负相关
- 等级：强支撑

### 🟡 部分支撑 (partial_support)

**定义**: 论文支撑声明的一部分、一个更窄的条件、或一个相关的但不等同的体系。

**适用条件**（满足 ≥1 条）：
- 论文研究的是相关但不完全相同的材料/体系
- 论文的结论方向一致但条件更窄（如不同温度范围、不同掺杂浓度）
- 论文支撑声明中的方法部分但不支撑结论部分
- 论文是综述，但引用了多篇直接支撑的原始研究

**示例**:
- 声明："Fe₃GeTe₂ 的居里温度随 Fe 空位浓度增加而降低"
- 支撑论文：在 Fe₃GeTe₂ 中研究了压力对居里温度的影响，未涉及空位
- 等级：部分支撑（支撑了 Fe₃GeTe₂ 居里温度可调制的概念，但未涉及空位机制）

### 🔵 背景支撑 (background_support)

**定义**: 论文为声明提供领域背景或先验知识，但不直接验证该声明。

**适用条件**：
- 论文建立了该领域的基础概念或方法框架
- 论文是经典综述，广泛引用于该领域的背景介绍中
- 声明是"已知"的背景信息，该论文是该领域的奠基性工作

**示例**:
- 声明："二维铁磁材料因自旋涨落抑制长程磁序而面临挑战"
- 支撑论文：Mermin-Wagner 定理的原始论文或经典综述
- 等级：背景支撑

### 🔴 矛盾/限制 (contradictory)

**定义**: 论文结果与声明方向相反，或对该声明的适用范围提出了重要限制。

**适用条件**：
- 论文报告了相反的效应或结论
- 论文发现了该效应的重要边界条件，而声明中未提及
- 论文的方法论论文质疑了声明中使用的方法的有效性

**示例**:
- 声明："Fe₃GeTe₂ 的居里温度随 Fe 空位浓度增加而降低"
- 支撑论文：报告了 Fe 空位浓度增加反而提高了居里温度（可能是不同制备条件）
- 等级：矛盾/限制

### ⚫ 无证据 (no_evidence)

**定义**: 摘要/全文内容与该声明无实质关联。论文可能涉及同一大领域，但研究的具体问题、方法或结论与声明无关。

**适用条件**：
- 论文主题相同但研究的是完全不同的机制/现象
- 论文与声明共享关键词但实际内容不相关
- 论文的摘要中没有提到声明中的核心要素

**示例**:
- 声明："Fe₃GeTe₂ 的居里温度随 Fe 空位浓度增加而降低"
- 支撑论文：研究了 Fe₃GeTe₂ 的能带结构，未涉及磁性或空位
- 等级：无证据

## 评估流程

对每条引用按以下顺序评估：

```
1. 阅读声明 → 提取核心主张
   ├── 研究对象是什么？（材料、体系、物种...）
   ├── 核心关系是什么？（增加/降低、导致、关联...）
   ├── 方法/技术是什么？（DFT、实验、计算...）
   └── 结论方向是什么？

2. 阅读摘要 → 提取论文实际内容
   ├── 论文研究了什么对象？
   ├── 论文发现了什么？
   ├── 论文用了什么方法？
   └── 论文的结论是什么？

3. 对比 → 判断匹配度
   ├── 对象是否一致？      → 不一致 → 至少降一级
   ├── 关系/结论方向是否一致？ → 相反 → contradictory
   ├── 方法是否相关？      → 方法论文 → 部分支撑
   ├── 是否有具体数据支撑？ → 仅有概念 → 背景支撑
   └── 是否有实质关联？    → 无关联 → no_evidence

4. 输出等级 + 推理
```

## 特殊规则

### 综述论文
- 综述用于背景声明 → 背景支撑
- 综述用于实验性声明 → 部分支撑（需注明是综述，建议引用原始论文）
- 综述用于方法性声明 → 部分支撑

### 自引
- 自引不自动降级，按相同标准评估
- 但报告中标注 `[自引]` 供用户判断

### 预印本
- 未经同行评议的预印本标注 `[预印本]`
- 支撑等级按相同标准评估，但报告中提示用户

### 撤稿/更正
- 如果 Zotero 或摘要中标注了撤稿/更正，必须标记并排除
- 不可引用已撤稿论文

