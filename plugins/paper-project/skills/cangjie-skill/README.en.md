# cangjie-skill

Distils accessible papers, preprints, books, textbooks, theses, technical
reports, classroom notes, or blogs into ATOM CARDs in the shared `prl-shared`
library.

It does not produce installable skills and is not a summarizer. The agent
proposes card types, tags, and write actions from the source and the user's
intended use. The user confirms them before general cards are written to
`/home/donk/plugins/research-knowledge/cards/atoms/` or physics cards are routed by category through
`/home/donk/plugins/research-knowledge/cards/physics/PHYSICS_INDEX.md`.

Read `../prl-shared/SKILL.md` before its index or any card. See
[SKILL.md](SKILL.md) for the complete protocol.
