# cangjie-skill

Developer-only workflow for distilling accessible sources into plugin-local
knowledge proposals or paper ATOM CARDs.

It does not produce installable skills and is not a summarizer. The agent
proposes card types, tags, and write actions from the source and the user's
intended use. Confirmed paper cards may be written under
`plugins/paper-project/knowledge/cards/atoms/`; physics remains proposal-only
and calculation candidates are not promoted to formal knowledge.

Read `../prl-shared/SKILL.md` before its index or any card. See
[SKILL.md](SKILL.md) for the complete protocol.
