# 杨声远（Shengyuan A. Yang）理论凝聚态面试：表达 DNA 与 E2 单目标审查示例（非本人原话）

> 本文依据论文摘要和官方研究介绍抽取 E2 学术审查框架，不是拟声、采访实录或可复用口头禅。下列示例每轮只检验一个认知动作。

## 公开材料可支持的结构

`物理缺口或低能对象 → 对称性保护/破缺条件 → 有效模型或第一性原理 → 特定响应 → 材料与探测`。

- [Nodal surface](https://journals.aps.org/prb/abstract/10.1103/PhysRevB.97.115125) 与 [CrPS4](https://research.polyu.edu.hk/en/publications/tunable-linear-and-nonlinear-anomalous-hall-transport-in-two-dime/) 支持以对称性和 SOC 条件组织机制判断。
- [QCP](https://arxiv.org/abs/1806.10458) 与 [VLC](https://pubmed.ncbi.nlm.nih.gov/32031831/) 支持把最小机制与材料实现分开讨论。
- [type-II Weyl](https://arxiv.org/abs/1604.04030) 与 [2D Weyl](https://arxiv.org/abs/2303.02971) 支持把主张落到可区分的观测指纹。

这适合模拟审查机制、条件、模型、响应和材料之间的连接；不支持断言其日常口头用词、追问节奏或个人偏好。

## E2 单目标示例

| 审查目标 | 单轮示例 | 回答锚点 |
|---|---|---|
| 定位现象 | 请界定要解释的低能现象。 | 费米能附近自由度或色散。 |
| 审对称性 | 请指出保护该交叉的一个最小对称性。 | 空间群、磁点群或反幺正操作。 |
| 压缩为模型 | 请写出与该对称性相容的最低阶项。 | 基与允许项。 |
| 导向响应 | 哪一个可观测量能区分该机制？ | 张量分量或谱学特征。 |
| 材料闭环 | 该材料的哪个能量尺度支持这一近似？ | 费米能位置或 SOC 尺度。 |
| 反事实 | 若关闭 SOC，该结论是否仍成立？ | 失效条件。 |

## 节奏与边界

1. 每轮只钉住一个缺口；机制、测量、替代解释和扰动不能并列在同一题中。
2. 先要求一个可证伪陈述，再在后续轮次审查其边界。
3. 模型、材料和实验读出在不同轮次互相校验；不可让其中一个替代其他证据。
4. 一次只改变一个假设，例如 SOC 或反演，而不并列多个扰动。
5. 对合著论文只能讨论公开论证结构，不能归因具体措辞、人格或私人评判。
