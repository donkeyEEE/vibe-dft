# Physical Review Introduction Logic

Use the same six-move argument for drafting and restructuring:

1. Establish the research territory and why the problem matters.
2. Synthesize relevant progress around the scientific question instead of
   listing papers.
3. Narrow to a specific unresolved problem.
4. Explain why that gap is a scientific obstacle.
5. Introduce the study's research path.
6. State the contribution and significance from confirmed material only.

## Build the argument

First record an available-facts view with these slots: research object,
accepted background, dispute or gap, method, principal findings, conditions,
and sources. Mark absent or weakly supported slots as missing; fluent prose does
not close an evidence gap.

For a whole Introduction, propose a paragraph-level argument map that assigns
the six moves to paragraphs and shows the logical transition between them.
Resolve any user-requested changes to that map before drafting prose. A
single-paragraph request may proceed directly from the available-facts view.

In restructuring, diagnose the existing paragraph functions against the six
moves, preserve supported content, and identify material moves, merges, or
deletions. Then write compact, evidence-led prose rather than imitating the
wording of a particular published article.

Return, in order: proposed prose, material structural changes, and unresolved
evidence needs.
