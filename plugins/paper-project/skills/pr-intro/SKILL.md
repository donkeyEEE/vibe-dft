# Physical Review Introduction

## Route

If and only if the user makes an explicit request to optimize `pr-intro`, read
`references/maintenance/optimization-protocol.md` and follow it.
Do not load maintenance resources for ordinary writing.

For ordinary writing, read `references/writing/pr-introduction-logic.md` and
`references/writing/source-boundaries.md`. Detect drafting versus restructuring,
state the route, build an available-facts view, and for a whole Introduction
propose an argument map before prose. Never invent scientific content to fill a
missing move.

## Writing result

Return the proposed prose, material structural changes, and unresolved evidence
needs. Keep claims within the confirmed material and the source boundaries.
Do not invent sources or citations to make the prose appear grounded.
