# PRL computational sensitivity as a result

If a scientific conclusion changes materially with a computational construction, approximation, or parameter choice, report that sensitivity as part of the result rather than hiding it as a technical caveat.

## Use

Compare the affected observables under clearly named constructions, identify qualitative agreements separately from quantitative differences, and explain the physical interpretation that is or is not stable. Use the comparison to delimit claims made by the calculation.

## Caveats

Sensitivity is not automatically a flaw; it can identify missing constraints or physically relevant model dependence. Avoid presenting one convenient construction as uniquely correct without independent justification.

## Evidence

XXP78P2F shows that Wannier and projector constructions change DFT+DMFT mass enhancements and occupancies, while some qualitative physics remains stable (abstract and main text). DFKEDU88 treats temperature-dependent correlated electronic structure as central to its magnetic-phase interpretation. SFW2U9Q9 attributes correlation changes to a spin-state and orbital-occupation mechanism across a substitution series.
