# PRL mechanism control comparator

When several mechanisms could explain a result, include a control or comparator that changes the proposed cause while preserving the most relevant alternative explanations.

## Use

Make the comparator's role explicit in the figure order and caption: state what is varied, what is held fixed, and which outcome would support or weaken the proposed mechanism. A control can be a structural variant, alternative interface, thickness, orientation, basis construction, or reference material.

## Caveats

A comparator only supports the mechanism it actually isolates. If several variables change together, label the result as suggestive rather than decisive and state the remaining confounders.

## Evidence

MXQN69IH uses non-ferroelectric and vacuum-gap control cases to separate barrier and ferroelectric roles (p. 1 and subsequent transport analysis). 9EF4M4XJ compares bulk magnetization with thin-flake anomalous Hall evidence for intrinsic order. GPH9XEST compares stacking configurations to attribute interlayer magnetism. ZMDQX8KE separates RKKY from other exchange mechanisms through lattice-size and thickness dependence.
