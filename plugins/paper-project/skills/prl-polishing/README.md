# `prl-polishing` 技能

[English](README_EN.md)

`prl-polishing` 用于按 PRL 的紧凑论证逻辑润色、重构或翻译物理学论文，同时保持作者的事实、证据边界和引用意图。

## 核心逻辑

技能先重建科学推理，再处理句子：

`条件或问题 → 中心主张 → 决定性证据 → 适用边界 → 物理后果`

它会特别检查：

- 理论预测是否区分计算签名与实验观测；
- 机制主张是否有能排除替代解释的控制或对照；
- 定量结论是否保留操作性判据、单位和不确定性；
- 有效模型、投影和计算构造的适用范围是否清楚；
- 主文是否包含中心论证必需的逻辑链，而不是把缺失环节留给补充材料。

## 适用任务

- PRL 摘要、引言、正文、结论和标题的结构重写与语言润色；
- 中文物理学手稿到投稿英文的转换；
- 理论、计算和实验段落的主张强度校准；
- 在不损失证据条件的前提下压缩篇幅；
- 检查预测、观测、解释、机制和因果表述是否混淆。

## 产出

- 多段文本先给出带稳定段落编号的修改范围总览；
- 默认逐段提供原文、修改稿与修改理由，并等待用户确认；
- 每段均可接受、继续修改、保留原文或暂时跳过；
- 所有段落确认后合并正文，并汇总修改决策与证据边界；
- 用户明确要求一次性处理时，直接给出完整润色稿与修改说明。

## 边界

- 不新增作者未提供的数据、机制、统计显著性、引用或新颖性主张。
- 代表性论文归纳得到的是写作默认值，不是 APS 强制要求。
- 投稿格式和长度限制以最新 APS 官方指南为准。
