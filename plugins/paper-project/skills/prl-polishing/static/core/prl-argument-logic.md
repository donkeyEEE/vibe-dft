# PRL argument logic

PRL-style compression is achieved by removing nonessential moves while preserving the complete scientific inference. Do not compress away the condition, decisive evidence, operational criterion, control, or boundary that makes a claim defensible.

## The argument unit

For every central claim, reconstruct this chain before polishing sentences:

`condition or question -> claim -> decisive evidence -> boundary -> consequence`

- **Condition or question:** the material state, symmetry, parameter regime, comparison, or unresolved problem.
- **Claim:** one precise statement that the paper's evidence can support.
- **Decisive evidence:** the observation, calculation, control, or quantitative comparison that tests the claim.
- **Boundary:** uncertainty, model assumption, parameter range, alternative mechanism, or sensitivity that limits the inference.
- **Consequence:** the physical meaning, measurable prediction, device implication, or interpretive constraint.

Not every sentence contains every move. The manuscript's main line must contain all five, in a sequence the reader can recover without guesswork.

## Evidence-led paragraph logic

Use one paragraph for one inferential job. Open with the question, condition, or claim; present the minimum evidence needed to assess it; then interpret only to the strength allowed by that evidence. If the next paragraph changes mechanism, condition, or evidentiary role, make that transition explicit.

For prediction papers, use `condition -> calculated signature -> observable consequence`. Do not describe an experimentally accessible signature as observed evidence.

For mechanism claims, name the control or comparator and state what it isolates. If several variables change together, retain the remaining alternative explanation.

For quantitative claims, retain the operational criterion, comparison condition, uncertainty or variability, and relevant units. A cleaner sentence is not an improvement if it removes how the number was defined.

For effective-model or computational claims, state the retained degrees of freedom, approximation, parameter regime, and sensitivity that affect the conclusion. Distinguish stable qualitative conclusions from construction-dependent quantitative results.

## Main text and supplement

Keep the claim-critical evidence and indispensable assumptions in the main text. Move derivations, extended sweeps, repeated traces, and reproducibility details to supplementary material only when the main text states what those materials test and points to them explicitly. Supplementary material cannot supply a missing logical link in the Letter.

## Compression test

After rewriting, ask:

1. Can the central claim be stated in one sentence?
2. Can each claim be traced to decisive evidence?
3. Are observation, interpretation, and prediction distinguishable?
4. Are quantitative criteria and model assumptions still visible?
5. Does the consequence remain within the evidence boundary?
