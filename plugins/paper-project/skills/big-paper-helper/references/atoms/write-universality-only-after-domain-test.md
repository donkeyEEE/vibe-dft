# 只在验证域内声称机制或描述符普适

机制或描述符只有在跨材料、组分、尺度或模型的验证域内成立时才可称为普适，并应同步报告反例和外推边界。

## Explanation

**适用范围：** 构效关系、描述符和机制外推。

应把这项约束作为相关结论成立的门槛；门槛未满足时，需要降低结论强度并声明缺失证据。

## Caveats

“可推广”与“普适”应使用不同证据门槛。
