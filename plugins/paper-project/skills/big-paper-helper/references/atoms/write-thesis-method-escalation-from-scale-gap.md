# 从尺度或模型缺口论证方法升级

新计算方法的引入应由现有方法无法覆盖的物理尺度、环境条件或模型边界驱动，而不应只以方法更复杂或更新颖作为理由。

## Explanation

**适用范围：** 多尺度、机器学习势、恒电势或非理想输运扩展。

应把这项约束作为相关结论成立的门槛；门槛未满足时，需要降低结论强度并声明缺失证据。

## Caveats

数值收敛不能替代目标物理验证。
