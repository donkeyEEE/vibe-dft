# 用漏斗结构收敛博士论文绪论

绪论应从应用或领域压力逐层收敛到材料体系、物理过程、现有证据缺口和本论文可回答的问题。

## Explanation

**适用范围：** 材料计算博士论文绪论。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

收敛层级应由问题决定，不是固定标题模板。
