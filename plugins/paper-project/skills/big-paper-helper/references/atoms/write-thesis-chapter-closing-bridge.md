# 用章末桥梁建立下一章的必要性

章末除总结本章外，还应明确留下的限制、继承给下一章的对象或判据，以及下一章为何必要。

## Explanation

**适用范围：** 具有递进关系的研究章小结。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

最后研究章改为指向全文综合而非下一研究章。
