# 按参数—观测—机制—后果解释扫描结果

参数扫描结果应按控制变量、直接观测变化、机制解释和物理或性能后果四层写作。

## Explanation

**适用范围：** 构效关系和参数调控段落。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

参数相关性本身不构成机制。
