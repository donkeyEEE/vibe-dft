# 从已声明的模型边界推导展望

计算论文的展望应从正文已声明的模型遗漏、尺度限制和未排除机制反推，而不是另起一组与证据无关的领域热点。

## Explanation

**适用范围：** 计算论文结论与展望。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

关键边界应在方法和结果中同步出现，不能只在结尾补写。
