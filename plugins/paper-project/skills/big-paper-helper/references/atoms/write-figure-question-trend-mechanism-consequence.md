# 按问题—趋势—机制—后果叙述图表

图表正文应依次说明图要回答的问题、可见趋势、量化差异、机制解释和对章节结论的后果。

## Explanation

**适用范围：** 材料计算图表叙述。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

图中不可见的因果需额外证据。
