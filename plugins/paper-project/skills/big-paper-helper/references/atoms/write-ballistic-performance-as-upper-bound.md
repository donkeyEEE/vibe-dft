# 把理想弹道输运性能标为理论上限

弹道输运和理想接触下的器件性能应标记为理论上限，并与包含散射、接触和缺陷的实际可达性能分开。

## Explanation

**适用范围：** DFT-NEGF理想器件论文。

应把这项约束作为相关结论成立的门槛；门槛未满足时，需要降低结论强度并声明缺失证据。

## Caveats

条件性卡；适用于弹道模型。

## References

- 张伟明（2025），《低功耗高性能一维晶体管的量子输运研究》：`Z-E012`，展望，PDF 第 164、165 页，direct：理想接触、弹道输运、声子热效应、制备和粗糙度构成明确边界。
