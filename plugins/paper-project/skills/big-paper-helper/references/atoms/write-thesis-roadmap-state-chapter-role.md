# 在绪论路线图中说明章节功能

绪论的章节安排应说明每章解决的问题、继承项、新增项和对全文贡献，而不只列出使用了什么方法。

## Explanation

**适用范围：** 绪论研究内容与章节安排。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

章节路线必须与正文实际结构一致。
