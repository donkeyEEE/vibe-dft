# 先建立静态前提再解释动力学增量

动力学章节前应先建立初末态结构、热力学驱动力和候选路径，再说明动态模拟新增了什么不可由静态结果得到的证据。

## Explanation

**适用范围：** 相变、扩散和反应动力学。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

条件性卡；不适用于没有明确定义初末态的过程。
