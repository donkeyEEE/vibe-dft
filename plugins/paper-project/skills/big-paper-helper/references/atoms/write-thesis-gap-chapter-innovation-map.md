# 建立科学缺口—章节—证据—创新映射

博士论文的每个研究章都应能从总科学缺口出发，映射到明确子问题、决定性证据和至少一项创新主张。

## Explanation

**适用范围：** 多个计算子课题整合成材料计算博士论文。

执行时应把主张中的要素逐项登记，并保留选择、排除或比较的理由，使过程可以回查。

## Caveats

缺口数不必等于章节数，但不能出现无来源缺口或无归宿章节。
