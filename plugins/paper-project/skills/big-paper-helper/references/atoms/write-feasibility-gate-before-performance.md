# 先通过可行性门槛再讨论性能

在讨论性能或机制前，应先证明模型结构、相态或器件设置在研究条件下具备基本可行性。

## Explanation

**适用范围：** 催化稳定性、相态模型和器件模型研究。

应把这项约束作为相关结论成立的门槛；门槛未满足时，需要降低结论强度并声明缺失证据。

## Caveats

计算可行性不等于实验可实现性。
