# 区分直接结果、机制解释与应用潜力

写作时必须把计算直接结果、由结果支持的机制解释和面向实验或器件的应用潜力分成三个证据等级，避免从模型输出跳到现实实现。

## Explanation

**适用范围：** 所有从计算模型连接实验、器件或应用的论文。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

机制解释本身也可能需要对照和敏感性验证。
