# 限定机器学习势的第一性原理精度域

“第一性原理精度”的机器学习势必须限定到训练域、验证物态和目标观测量，并报告缺失的长程或反应物理。

## Explanation

**适用范围：** 机器学习势论文。

应把这项约束作为相关结论成立的门槛；门槛未满足时，需要降低结论强度并声明缺失证据。

## Caveats

条件性卡；需要更多方法来源强化。
