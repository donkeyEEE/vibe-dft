# 在目标观测量上验证新方法

新方法用于核心结论前，应在目标物态、物性和动力学观测量上验证，而不能只报告能量或拟合误差。

## Explanation

**适用范围：** 方法升级、机器学习势和更真实环境模型。

应把这项约束作为相关结论成立的门槛；门槛未满足时，需要降低结论强度并声明缺失证据。

## Caveats

不同方法的目标验证集不同。
