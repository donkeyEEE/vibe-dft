# 用分阶段筛选漏斗缩小候选空间

大候选集合应通过低成本必要条件逐层缩小，再对少量候选计算完整路径、机制和稳健性。

## Explanation

**适用范围：** 高通量催化或多材料器件筛选。

执行时应把主张中的要素逐项登记，并保留选择、排除或比较的理由，使过程可以回查。代表体系的选择必须可追溯，并至少保留能检验筛选判据的必要对照。

## Caveats

早期门槛可能排除非典型机制，需说明筛选偏差。
