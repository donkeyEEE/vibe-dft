# 把研究缺口写成尚不可获得的观测量

研究缺口应说明现有实验或计算为何无法获得某个结构、轨迹、机制或尺度观测量，而不只说研究较少。

## Explanation

**适用范围：** 选题依据与科学问题表述。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

“无法回答”需要文献和方法边界支持。
