# 用共享证据脊柱连接不同研究章

不同研究章应复用一组稳定的证据功能位，例如模型可靠性、直接结果、机制、性能后果和边界，以支持跨章综合而非只共享研究对象。

## Explanation

**适用范围：** 多体系、多物态或多器件论文。

该概念用于全文级结构审计：具体章节可以采用不同观测量，但承担的证据功能必须能够对应。

## Caveats

证据功能可复用，具体小节标题和观测量不能机械统一。
