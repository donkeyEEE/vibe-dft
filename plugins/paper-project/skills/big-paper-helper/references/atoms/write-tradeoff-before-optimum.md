# 先呈现权衡与可行窗口再报告最优值

优化章节应先报告参数对多个目标的相反影响和可行窗口，再给出最优设置，避免只展示单点最好结果。

## Explanation

**适用范围：** 多目标材料和器件优化。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

目标权重需由应用或物理问题定义。
