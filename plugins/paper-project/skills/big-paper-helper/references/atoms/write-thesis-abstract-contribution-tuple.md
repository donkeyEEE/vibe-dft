# 用五元组表达摘要中的单项贡献

摘要中的单项贡献应包含研究对象或变量、采用的方法、决定性结果、机制解释和意义边界。

## Explanation

**适用范围：** 计算材料博士论文摘要贡献段。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

未直接支持的应用意义必须降格为潜力。
