# 用观测量、机制链与边界定义创新

每项创新应绑定一个决定性观测量或对照、一个机制链和一个明确适用边界，避免只以研究对象首次出现定义创新。

## Explanation

**适用范围：** 创新点撰写与审核。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

方法创新和理论概念创新可能需要不同观测契约。
