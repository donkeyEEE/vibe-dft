# 为高风险技术术语附加条件和判据

“真实条件”“第一性原理精度”“理论性能极限”“协同优化”等高风险术语必须同时声明其模型条件和判定指标。

## Explanation

**适用范围：** 计算论文术语治理。

写作或审核时，应检查正文是否显式呈现该信息关系，而不是让读者依靠目录、图题或跨章猜测补全。

## Caveats

具体条件随方法而变化。
