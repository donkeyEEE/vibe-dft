# 材料计算博士论文写作卡片索引

该索引用于在当前 `big-paper-helper` skill 中按写作阶段和计算方法选择本地知识卡片。卡片来源信息用于知识溯源，不构成用户论文可以直接引用的参考文献。

## 读取规则

先按写作阶段选择最小 tag 集，再读取相关卡片；不得一次性加载全部卡片。方法专用 tag 仅在任务涉及对应方法时读取。
