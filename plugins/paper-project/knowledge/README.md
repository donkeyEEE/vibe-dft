# Paper Project Knowledge

This directory contains optional paper-writing and journal knowledge shipped
with `paper-project`. It is part of the plugin source and release boundary, not
an independently installed repository.

Formal cards live under `cards/`. Work in progress lives under `candidates/`
and is never consumer input. Cangjie remains a developer-only workflow while
its future write and governance model is intentionally left open.

Consumers must follow [CONSUMER_CONTRACT.md](CONSUMER_CONTRACT.md). Formal
content may be read from an uncommitted working tree during development.
