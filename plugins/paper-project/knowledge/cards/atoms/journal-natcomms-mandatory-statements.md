# Nature Communications mandatory statements

Nature Communications submissions require specific availability, contribution, competing-interest, and reporting disclosures that must contain verifiable details rather than placeholders.

Include Data Availability with repositories, accession numbers, or DOIs; Code Availability when custom code was used; author contributions; competing interests; and the relevant Nature Portfolio Reporting Summary. Invalid or unresolved accession identifiers can block publication.
