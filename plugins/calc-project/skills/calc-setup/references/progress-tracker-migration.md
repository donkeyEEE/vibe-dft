# 旧进度记录迁移

仅在存在 `.calc-project/tracker.json` 时读取。字段和维护要求见
[进度记录契约](../../../resources/progress-tracker.md)与
[维护契约](../../../resources/progress-tracker-maintenance.md)。

`calc-setup` 在本次获准维护范围内，从各 RQ.md 和已发布 Spec 分别建立并核实 RQ 内的记录，
更新项目约定及忽略规则；全部完成后删除旧项目级派生记录。
迁移未完成时保留旧文件并报告未完成项。日常查询与状态维护使用 RQ 内的记录，不回退到旧文件。
保留 `.calc-project/` 内的其他文件及其报告忽略规则。
