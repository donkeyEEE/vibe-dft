# 计算项目管理

本上下文定义 Calc Project 用于组织科研计算工作的通用语言。它是新计算项目的初始术语基线；项目可以按已确认的项目语义直接调整或重新定义其中的术语。

## Language

**计算项目（Calculation Project）**:
围绕一个研究目标组织的计算工作整体，对应一个 `<project-root>/`。
_Avoid_: 项目目录，计算仓库

**计算项目结构（Calculation Project Structure）**:
计算项目的管理层级，由并列的计算笔记结构和计算工作结构组成。计算笔记结构组织项目的稳定知识；计算工作结构组织可执行、可跟踪和可交接的计算工作。
_Avoid_: 目录结构，计算工作流

**计算笔记（Calculation Notes）**:
沉淀研究计划、计算规范、结果解释和问题排查知识的记录，位于 `01<main-line-slug>/` 下的笔记分类中。
_Avoid_: 任务记录，运行日志

**计算笔记结构（Calculation Notes Structure）**:
计算项目中按研究主线和知识职责组织计算笔记的层级。一个 `01<main-line-slug>/` 研究主线容器下分为研究计划、计算规范、计算笔记、问题排查、理论笔记、文献笔记、图表与阶段汇总和归档八类。
_Avoid_: 执行数据结构，数据根，笔记文件列表

**计算工作结构（Calculation Work Structure）**:
计算项目中组织可执行、可跟踪和可交接工作的层级。它以数据根为边界，容纳任务导航索引、计算线、计算任务、任务输入、Run 产物和（可选）工作流。
_Avoid_: 执行数据结构，计算笔记结构，计算工作流

**数据根（Data Root）**:
计算工作结构的项目级边界，容纳任务导航索引、计算线和（可选）工作流，以及计算线下各计算任务的管理记录、任务输入和 Run 产物。它对应 `02原始数据/` 或 `02<slug>-原始数据/`。
也可以被称为原始数据目录。
_Avoid_: 计算目录

**计算线（Calculation Line）**:
数据根下根据项目的科研关系组织一组计算任务的层级；中间目录的数量和含义由项目定义。
_Avoid_: 固定三层路径，工作流

**工作流（Workflow）**:
为完成一个跨阶段计算目的而定义的阶段顺序、任务依赖、交接产物和验收关系。工作流连接计算任务，但不拥有任务身份、路径或生命周期状态；多任务工作流可由计算线根部的 `WORKFLOW.md` 记录。
_Avoid_: 计算线，计算任务，目录层级

**计算任务（Calculation Task）**:
具有独立科学目的、任务输入和生命周期状态的最小可独立跟踪单元，对应同时包含 `calc-task.yaml`、`README.md` 和 `inputs/` 的任务目录。
_Avoid_: Run，作业，计算步骤

**计算任务结构（Calculation Task Structure）**:
一个计算任务内部的标准组织关系，由任务元数据、任务摘要、任务输入和零个或多个 Run 组成。
_Avoid_: 计算项目结构，计算线，任务目录列表

**任务元数据（Task Metadata）**:
计算任务的机器可读权威记录，包含任务身份、本地与远程路径、生命周期状态和轻量文件索引；对应任务目录中的 `calc-task.yaml`。
_Avoid_: 任务摘要，任务导航索引，项目日志

**任务摘要（Task Summary）**:
面向人的计算任务目的、现状和重要事件摘要，对应任务目录中的 `README.md`；它不能覆盖任务元数据。
_Avoid_: 任务元数据，任务导航索引

**任务输入（Task Inputs）**:
经确认并供计算任务的 Run 使用的输入与任务专用脚本，对应任务目录中的 `inputs/`。
_Avoid_: 计算模板，Run 输出，Run 输入目录

**运行（Run）**:
计算任务的一次独立执行尝试，其输出和作业日志归档在任务下由 `<run-tag>/` 表示的目录中。失败、取消和重跑均是 Run，不是新的计算任务。
_Avoid_: Run 标识，run-tag，计算任务，作业

**覆盖型重算（Overwrite Run）**:
在明确选择覆盖后，沿用已存在的 `<run-tag>/` 目录名来创建新 Run，并替换其中的旧 Run 记录。这是有损操作，被替换的 Run 不再可由计算项目追溯。
_Avoid_: 普通重跑，续算，Run 复用

**任务导航索引（Task Navigation Index）**:
专指数据根下的 `NOTE-doing.md`：它是面向跨会话交接的任务导航表，汇总任务路径、状态和下一步行动，但不能覆盖任务元数据。
_Avoid_: 项目进行记录，任务元数据，项目日志

**本地副本（Local Copy）**:
同一计算任务数据在本地工作环境中的受管位置。
_Avoid_: 主数据，本地任务

**远程副本（Remote Copy）**:
同一计算任务数据在计算集群中的受管位置。
_Avoid_: 主数据，远程任务

**计算模板（Calculation Template）**:
经批准、可复用于生成任务输入的来源资产，收录于 `calculation_templates/`。
_Avoid_: 输入快照，任务输入
