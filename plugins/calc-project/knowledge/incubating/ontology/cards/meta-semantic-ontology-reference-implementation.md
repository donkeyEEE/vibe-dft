# 最小语义本体参考实现

一个最小语义本体实现可以用 Turtle 表达类、公理与属性，用 SHACL 表达显式数据形状，再由推理与校验代码分别执行两条保障通道。

## Caveats

教学代码不能直接视为生产实现；依赖版本、推理 profile、数据规模、错误处理和部署要求必须另行验证。
