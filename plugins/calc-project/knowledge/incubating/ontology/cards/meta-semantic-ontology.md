# 语义本体

语义本体是以形式语义和可判定推理为核心的领域概念化规约，其目标不是仅存储事实，而是用公理从显式知识推出隐含知识。

## Caveats

不能把所有 Schema、知识图谱或规则集都称为语义本体；具体标准能力应以一手规范复核。
