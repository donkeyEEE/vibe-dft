# Agent 关键 SOP 外部化

对安全或合规关键流程，应把必需步骤、顺序、条件分支与不可跳过项外部化为可校验 SOP，而不是依赖 LLM 每次自由生成计划。

## Caveats

开放式探索任务不应被强制压成单一路径；只固定风险关键的不变量和检查点。
