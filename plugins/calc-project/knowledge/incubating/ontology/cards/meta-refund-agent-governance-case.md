# 电商退款 Agent 治理教学案例

电商退款教学案例展示了订单核验、金额阈值、审批条件和工具调用顺序如何把开放式用户请求收敛为可审计的受控执行流程。

## Caveats

金额阈值与审批权限是组织配置，不能从示例直接复制。
