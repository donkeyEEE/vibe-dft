# 四层 Agent Harness

Agent Harness 可以按概念、规则、SOP 和技能四类职责组织校验，分别约束认知对象、行为准则、步骤顺序以及工具输入输出契约。

## Caveats

四层是教学性的职责分解，不要求部署为四个独立服务；实现可以合并，但相应校验责任不能消失。
