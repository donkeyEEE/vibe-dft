# Cite the verified primary source

Cite the source that produced the data, method, claim, or conclusion being asserted, rather than a secondary source that merely discusses it.

Use a secondary source for that secondary source’s interpretation, comparison, or critique. Do not cite a work that has not actually been read and verified, and do not treat online availability as public-domain permission.
