# Attribute intellectual debt

Make prior ideas, methods, data, and interpretations visibly attributable instead of minimizing them to exaggerate originality.

State how the present work builds on earlier work, who supplied the earlier contribution, and where a reader can find it. Originality is commonly an extension or combination of prior knowledge, not a reason to obscure that debt.
