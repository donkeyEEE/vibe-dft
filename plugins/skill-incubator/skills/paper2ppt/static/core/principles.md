# Core principles

Use the paper's scientific argument—not section order—as the deck spine:
problem, gap, method, decisive evidence, validation, consequence, and limits.
The chosen paper-type fragment refines this order without weakening evidence.

- Default to simplified Chinese while preserving technical terms and the
  Terminology Ledger.
- Produce a real PPTX and complete project package, not only an outline.
- Read in two passes and extract only assets selected by the confirmed plan.
- Keep original scientific figures by default. Select readable panels without
  altering data, axes, legends, scale bars, labels, or necessary context.
- Every figure retains provenance; every claim is supported or marked as a
  source gap.
- Speaker notes are required. Motion, timed advance, narration, and media are
  outside this scientific presentation contract.
- Stable candidate and final artifacts replace backup or timestamped variants.
