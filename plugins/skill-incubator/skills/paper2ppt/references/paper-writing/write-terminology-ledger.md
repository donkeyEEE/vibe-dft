# Terminology ledger

Create and enforce one canonical name for each recurring scientific entity before drafting or polishing prose.

Record methods, models, datasets, materials, biological entities, metrics, units, symbols, abbreviations, and defined concepts. For each, retain the canonical form, first-use expansion, observed variants, and a resolution for collisions. Once chosen, do not vary terminology for stylistic novelty; if a user changes a term, update every occurrence rather than only the current passage. Do not invent a missing or ambiguous term.
