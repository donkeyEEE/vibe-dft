# Failure recovery

Recover only within paper2ppt's preparation boundary:

| Failure | Recovery |
|---|---|
| Source normalization | Report the failed source and use `paper-project:liteparse` with a readable local file or pasted text. |
| Missing evidence | Mark the gap and revise the academic emphasis instead of inventing content. |
| Figure crop review | Expand or replace the crop until every Source and Preserve item is valid. |
| Invalid brief | Add the required headings, delivery statements, or image provenance. |
| Non-empty destination | Ask for a different empty output location; preserve all existing files. |
| Handoff invocation | Report the exact builder command and JSON error without creating partial output. |

Once `$ppt-master` has accepted the handoff, rendering and export recovery
belongs to PPT Master. Do not substitute a local rendering route.
